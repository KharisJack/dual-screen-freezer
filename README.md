**双屏等比定屏工具 (Dual Screen Freezer)** 是一款专为双屏教学、演讲汇报、会议演示及多任务协作环境打造的系统级高效辅助工具。它能够一键完美抓拍并无缝冻结副屏（大屏/投影）画面，同时让主屏（讲台屏）保持自由操作，彻底解决演示过程中的隐蔽性与多任务调度难题。

## ✨ 核心特性

* ❄️ **一键全景物理像素冻结 (`F1`)**：高保真抓拍当前画面并静默锁定副屏，主屏可自由切换应用、备课或处理私密事务。
* 📺 **一键恢复双屏镜像 (`F2`)**：瞬间解锁冻结，平滑恢复双屏复制（镜像）模式。
* 🚀 **跨屏窗口强制抓回 (`F3`)**：一键将误甩到副屏/大屏上的所有应用窗口平滑迁移回主屏，告别“找不到窗口”的尴尬。
* 🖤 **副屏纯黑遮挡模式**：提供一键黑屏遮挡支持，适合临时暂停演示或隐蔽准备教学内容。
* 🎯 **鼠标双键同按光标归位 (`LButton + RButton`)**：同时按压鼠标左键与右键，指针瞬间归位至主屏中央，大屏环境中不再迷路。
* 🛡️ **PPT 状态守卫与抗抖动引擎**：深度适配 WPS 与 Microsoft Office PowerPoint，退出放映时自动防御系统切屏抖动，保持定屏状态稳如磐石。
* 📐 ** Per-Monitor DPI v2 感知**：完美兼容多屏不同缩放比例（DPI）与高刷新率显示器。

## ⌨️ 快捷键速查

| 快捷键 | 功能描述 |
| :--- | :--- |
| **`F1`** | 进入屏幕冻结模式（副屏定格，主屏自由操作） |
| **`F2`** | 解除定屏 / 黑屏，恢复双屏同步镜像 |
| **`F3`** | 强制抓回副屏上的所有非系统窗口至主屏幕 |
| **`F4`** | 重置脚本状态并清理配置数据 |
| **`鼠标左键 + 右键`** | 强制将鼠标光标归位至主屏幕正中央 |

## 🛠️ 技术架构与优化

1. **双层 GUI 装甲与 DWM 豁免**：应用 `DWMWA_DISALLOW_PEEK` 与 `DWMWA_EXCLUDED_FROM_PEEK`，杜绝 Windows 任务栏预览与 Peek 悬停导致的抓拍层闪烁。
2. **零阻断穿透置顶**：通过 Win32 API 直接操纵窗口位置与层级，确保定屏层始终覆盖副屏且不抢占系统焦点。
3. **拓扑自愈与防抖**：内置动态拓扑巡检引擎，实时监控显示设备连接状态，具备脉冲式切屏压制与防抖熔断能力。
4. **低开销降噪日志**：结构化运行日志存储于 `%AppData%\.ScreenGuardData\Logs\`，支持指纹去重与零变更静默。

## 🚀 快速开始

### 依赖环境
* **操作系统**：Windows 10 / Windows 11
* **运行环境**：[AutoHotkey v2.0+](https://www.autohotkey.com/)（若运行 `.exe` 编译版本则无需安装）

### 安装与运行
1. 下载最新的 Release 发行包（或直接运行 `DualScreenFreezer.ahk`）。
2. 首次运行将自动弹出 **智能启动向导**，引导检查显示拓扑与开机自启设置。
3. 运行后图标将静默托管于系统托盘区，使用快捷键即可随心控制。
